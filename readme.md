# 🛒 E-Commerce Sales Analysis using SQL

## 📌 Project Overview
This project focuses on analyzing an e-commerce sales dataset using SQL to extract meaningful insights about customer behavior, product performance, and overall business trends.

The analysis demonstrates the use of SQL for real-world data analysis tasks including querying, filtering, aggregation, and reporting.

---

## 🎯 Objectives
- Analyze sales data to uncover trends and patterns  
- Identify top-performing products and customers  
- Perform data aggregation using SQL queries  
- Generate insights useful for business decision-making  

---

## 🛠️ Tools & Technologies
- SQL (SQLite / MySQL)
- CSV Dataset
- DB Browser / Online SQL Compiler

---

## 📂 Dataset
- `ecommerce_sales.csv`

### Dataset Includes:
- Order ID  
- Customer ID  
- Product details  
- Quantity & Price  
- Sales / Revenue information  

---

## 🧾 SQL Tasks Performed
- Creating tables and importing dataset  
- Selecting and filtering data (`SELECT`, `WHERE`)  
- Sorting results (`ORDER BY`)  
- Aggregation (`SUM`, `AVG`, `COUNT`)  
- Grouping data (`GROUP BY`)  
- Advanced queries for insights  

---

## 📊 Key Analysis & Insights
- Identified top-selling products based on revenue  
- Analyzed customer purchasing patterns  
- Calculated total sales and average order value  
- Found highest contributing customers  
- Observed trends in product demand
